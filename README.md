# IPTV-плеер для Android TV — сборки

Здесь лежат готовые сборки приложения. Исходный код — в отдельном закрытом репозитории.

## Установка

Проще всего — открыть на приставке или телефоне адрес **tv.russanova.kz** и скачать приложение оттуда. Либо взять файл `IptvTv.apk` со страницы [последней сборки](https://github.com/DeulinD/IptvTv-releases/releases/latest).

При первой установке Android спросит разрешение ставить приложения из этого источника — его нужно дать один раз.

Новое устройство получает список каналов после того, как владелец разрешит его у себя. До этого приложение запустится, но каналов не покажет.

## Обновления

Раз в сутки приложение само проверяет, нет ли новой сборки, а по кнопке «Обновить» в списке каналов — сразу. Новую сборку оно скачивает само и открывает системный установщик: остаётся нажать «Установить».

## Что в каждой сборке

| Файл | Назначение |
|---|---|
| `IptvTv.apk` | само приложение |
| `version.txt` | номер сборки — по нему приложение понимает, что пора обновиться |

Адреса `…/releases/latest/download/IptvTv.apk` и `…/releases/latest/download/version.txt` всегда ведут на последнюю сборку.

## Требования

- Android 6.0 и новее
- приставка или телевизор на Android TV; на телефоне тоже работает — со своим видом под касания
