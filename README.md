# IPTV-плеер для Android TV — сборки

Здесь лежат готовые сборки приложения. Исходный код — в отдельном закрытом репозитории.

## Установка на приставку

Скачайте последнюю сборку со страницы [Releases](https://github.com/DeulinD/IptvTv-releases/releases/latest) и откройте файл `.apk` на приставке.

При первой установке Android спросит разрешение ставить приложения из этого источника — его нужно дать один раз.

## Обновления

Дальше приложение обновляется само: оно проверяет наличие новой сборки при запуске и ставит её без участия зрителя. Скачивать что-либо вручную больше не потребуется.

## Что внутри релиза

| Файл | Назначение |
|---|---|
| `app-release.apk` | само приложение |
| `version.json` | номер последней версии, по нему приложение понимает, что пора обновиться |

## Требования

- Android 6.0 и новее
- приставка или телевизор на Android TV; работает и на обычном Android-устройстве
